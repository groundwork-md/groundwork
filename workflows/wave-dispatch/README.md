This whole category is **not the default workflow** — single-session work is. Everything here is a hazard/rule discovered during past parallel/multi-agent dispatch (multiple concurrent rails working the same repo), kept ready for whenever that mode is deliberately invoked again, not something to apply by default.

If you're about to dispatch multiple concurrent agents against the same repo, read through this folder first — every file here was learned from a real incident. If you're working solo, none of this applies except where a note explicitly says otherwise (a few — like the git-verification-discipline ones — generalize beyond parallel dispatch specifically).
